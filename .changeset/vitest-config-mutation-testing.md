Adds mutation testing beside the Vitest config. `@cosyte/vitest-config/stryker` exports `cosyteStryker(options?)`, a StrykerJS config for the Vitest runner (resolved from this package, so it works under pnpm), with per-test coverage in Vitest's forks pool, every mutant kept (static ones too), no score threshold of its own, and the JSON report at `reports/mutation/mutation.json`. The new bin, `cosyte-mutate`, runs `full` over everything the config names, or `changed --base <ref>` over only the source files changed against the merge base of that ref and HEAD, writing `reports/mutation/changed.json`; a change with no changed source file starts no run, writes an empty report and exits 0, and a run that cannot start exits 2. `@cosyte/vitest-config/mutate` is the bin's body. `@stryker-mutator/core` and `@stryker-mutator/vitest-runner` 10 are optional peer dependencies, so a package that does not mutate installs nothing new; the package now depends on `@cosyte/script-utils` for reading what a change touched. `cosyteVitest` also adds the `json-summary` coverage reporter, so a coverage run writes `coverage/coverage-summary.json`, the totals `cosyte-ratchet` compares with a floor file; the `text`, `html` and `lcov` reporters, the thresholds and the excludes are unchanged.
